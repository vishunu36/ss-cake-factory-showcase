# SS Cake Factory Website

A modern and responsive cake shop website built using React and Vite.

## Live Demo

https://ss-cake-factory-showcase.vercel.app

## Features

- Responsive design
- Cake gallery showcase
- WhatsApp ordering integration
- Contact information
- Location integration
- Mobile-friendly layout
- Fast loading performance

## Technologies Used

- React.js
- Vite
- JavaScript
- HTML5
- CSS3
- Vercel

## Installation

Clone the repository

```bash
git clone https://github.com/vishunu36/ss-cake-factory-showcase.git
```

Install dependencies

```bash
npm install
```

Run locally

```bash
npm run dev
```

Build project

```bash
npm run build
```
